# Bellows Digital

Portfolio site for Bellows Digital, a bilingual (English/Spanish) web design and development practice run by Juan Vizcaino.

**Live site:** https://bellowsdigital.com

## Features

- Fully responsive, single-page layout built with vanilla HTML, CSS, and JavaScript (no frameworks or build step)
- Scroll-driven pinned animation that breaks the logo apart and reassembles it
- Live English/Spanish language toggle, remembered between visits
- Scroll reveals, sticky header, and back-to-top button
- Respects `prefers-reduced-motion`
- Contact form delivered by [FormSubmit](https://formsubmit.co)

## Run locally

Everything lives in `index.html`. Open it in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Hosted on Netlify. Pushing to `main` deploys automatically.
